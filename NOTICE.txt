Hype Toolkit 1.0

An unofficial fan project for Hype: The Time Quest. Not affiliated with or endorsed by Ubisoft or Playmobil.
Free to use for personal, non-commercial purposes. Provided as is, without warranty of any kind.

The toolkit contains no game files. It needs your own installed copy of the game and only reads it: nothing in
your game folder is changed. Everything it shows (sounds, dialogue, pictures, models, saves) comes from that copy.
Its own data (an index and decoded sounds) lives in %LOCALAPPDATA%\hypekit and can be deleted at any time.

Thanks to the Raymap project (byvar/raymap) for documenting the engine's file layouts.
